SHELLDIVER OFFICE MODS 1.0.0
Tested on: Shelldiver v1.0.2.300.020, Aurie 2.0.2, YYToolkit 5.0.0c, AurieSharp 0.0.3, BubbleLib 0.0.2

BACK UP YOUR SAVE FIRST
Copy this folder somewhere safe: %APPDATA%\Shelldiver\save

INSTALL
1. Install the .NET 9 Runtime (x64):
   https://dotnet.microsoft.com/download/dotnet/9.0
2. Download AurieInstaller.exe:
   https://github.com/AurieFramework/Aurie/releases/tag/v2.0.0b
   Run it, tick "Allow C# mods", click "Find my game!" and select Shelldiver.exe.
3. Download BubbleLib v0.0.2:
   https://github.com/TP-repo/BubbleLib/releases
   Copy its "mods" folder into your Shelldiver folder.
4. Extract ShelldiverOfficeMods zip into your Shelldiver folder, merging "mods".
5. Optional: extract the Trainer zip the same way.

Your Shelldiver folder is usually:
C:\Program Files (x86)\Steam\steamapps\common\Shelldiver

Start the game. A Mods option on the main menu means it worked.

FEATURES
Office       Walk left from the hammock and press interact to open the menu.
Land         New land on both sides of the village.
Dev Console  Press the ` key. Commands: help, clear, npc [on|off].
New Game+    On the main menu. Resets progress, keeps some bonuses, closes the game.
Trainer      Optional. Office > Mods > Trainer.

OFFICE MENU CONTROLS
Move         W/S, arrow keys or mouse
Select       Enter, Space or left-click a label
Change value Mouse wheel, A/D, Left/Right, or left-click to lower and right-click to raise
Back/Close   Esc

KNOWN ISSUES
- A game update or "Verify integrity of game files" can undo the install. Repeat steps 2 to 5.
- If Steam Cloud reports a save conflict after New Game+, choose the local files.
- The Trainer changes values the game may save, and Steam achievements may still trigger.
- The Office prompt always shows E, even if your interact key is different.

UNINSTALL
Verify the game files in Steam, then delete the "mods" folder from your Shelldiver folder.
Saves are kept. New Game+ backups are in %APPDATA%\Shelldiver\ngplus_backups.
